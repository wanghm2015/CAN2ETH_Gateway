Based on the official TC3xx chip drivers, FreeRTOS integration has been completed to support multi-task execution. 
The main directory contains the official code, while the developer's custom code is uniformly placed in the "feature" directory. 
This directory includes core functionalities that enable data forwarding and routing between CAN and Ethernet.

TC3xx チップの公式ドライバに基づき、FreeRTOS の統合を完了し、マルチタスク実行をサポートしています。
メインディレクトリには公式コードを配置し、開発者が作成したカスタムコードはすべて「feature」ディレクトリに統一的に格納します。
このディレクトリにはコア機能が含まれており、CAN とイーサネット間のデータ転送およびルーティングを実現します。
